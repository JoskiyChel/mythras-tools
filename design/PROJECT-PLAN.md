# Companion — план работ и фактический статус

Дата снимка: **17.11.2026**. Ветка: `master`; фичевая ветка слита fast-forward
(`38b49e3`). Это рабочая карта проекта; историческое сравнение с форком xe-n0x
остаётся в [COMPETITOR-FORK-ANALYSIS.md](COMPETITOR-FORK-ANALYSIS.md), а решения и
открытые вопросы — в [COMPANION-OPEN-QUESTIONS.md](COMPANION-OPEN-QUESTIONS.md).

## 1. Что уже сделано

### 1.1. Основа Companion

- Отдельный лист `#/view/companion`: навыки слева, карточка персонажа с
  анатомической плитой, список локаций, характеристики, числовые плитки,
  эффекты и пять вкладок.
- Семь локаций d20, текущие и максимальные HP, AP, травмы на локацию.
- Магические дисциплины Companion: пулы Devotion, Intensity, Animism,
  Mysticism, Sorcery, Folk Magic; несколько культов; модификаторы магии.
- Совместимость старых сохранений: миграции травм, `Skill.id`, отсутствующих
  текущих HP; JSON и библиотечные резервные копии.

### 1.2. Визуальное направление A

- Тёмная краснофигурная керамика: глиняные поверхности, терракота, бронза.
- Палитра и Material-тема в `src/ui/_tokens.scss`, `_material.scss`,
  `_components.scss`; тёмная `color-scheme`, читаемые hover-пары.
- Анатомическая плита: отсечение рисует культю и линию разреза, `Увечье` —
  деформацию и постоянный `locationHp −1`, `Пронзена` — встроенную стрелу,
  `Кровотечение` и `Шрам` — наложения на часть тела.
- Плита без постоянных цифр HP: значения собраны в списке локаций и редакторе.

### 1.3. Эффекты и снаряжение в листе

- Модальный редактор эффектов и травм; модификаторы показываются
  по-человечески (`Характеристика: STR +1`), включая `locationHp`.
- Описание эффекта в списке ограничено двумя строками; кнопки
  редактирования/удаления закреплены; клик по карточке открывает полный
  редактор с описанием и модификаторами.
- Добавление оружия, брони, предметов и заклинаний из листа: поиск, фильтр
  оружия по боевым стилям, броня по локации, магические традиции.
- «Становление»: черновик характеристик и навыков, прошлое → прибавка → итог,
  изучение профессионального навыка, стрелки производных атрибутов;
  «Применить»/«Отмена».

### 1.4. Игровой цикл P2

- `services/dice.ts`: d2–d100, до 50 кубиков, модификаторы, выражения
  `2d6+1d8−3`, криптографический random с rejection sampling, ручной ввод
  физических значений.
- `services/skill-check.ts`: сложности, Critical/Fumble по книжному `ceil`,
  степень успеха и объяснение; augment одним вспомогательным навыком.
- Окно проверки навыка: виртуальный/физический d100, сложность, история
  проверок только в сеансе.
- Общий лоток «Кубики»: пресеты, выражения, виртуальный/физический режим,
  история бросков только в сеансе, переключатель анимации.
- **Undo/redo изменений персонажа** и журнал изменений в шапке: снимки в
  памяти (до 30), подписи вида «HP: Грудь 5 → 6», «Снят эффект «Усталость»».
  История не попадает в JSON.

### 1.5. Адаптивность и читаемость

- Лист ограничен 1438 px, карточка и вкладки — 1114 px, центрируются.
- Характеристики — 58 px (на узких экранах только уменьшаются), числовые
  плитки — 111 px (до 1400 px две колонки), эффекты — 485 px, строки локаций —
  36 px, вкладки переносятся, таблица усталости на телефоне становится
  карточками.
- Аудит 2560–320 px: пересечений, обрезаний и горизонтальной прокрутки нет.
  Подробности — в [SHEET-LAYOUT-AUDIT.md](SHEET-LAYOUT-AUDIT.md).

## 2. Что осталось

Порядок выбран по влиянию на игру: сначала здоровье и эффекты, затем режим
«За столом», потом углубление «Становления» и «Опыт».

### P1. Здоровье и эффекты — следующий блок

- [ ] Подписи **Minor / Serious / Major** в строке локации и редакторе.
- [ ] «Восстановить все ОЗ» с подтверждением и записью в сеансовую историю.
- [ ] Заметка к травме (не смешивать с общим описанием эффекта).
- [ ] Эффекты части тела: штрафы к локации, оглушение, конфликты
  модификаторов.
- [ ] Включение/выключение эффекта без удаления; визуальный признак
  неактивного эффекта.
- [ ] Решить автоистечение эффектов; по текущему предложению — без
  автоистечения, снимает ведущий.
- [ ] Проверить максимум HP после травмы на всех путях лечения/урона.

### P0. Режим «За столом / Редактирование»

- [ ] Явный переключатель режима; в игре редактирование профиля, травм и
  снаряжения заблокировано, HP/AP/MP/Luck и проверки доступны.
- [ ] Компактный статус сохранения в шапке вместо постоянной строки.
- [ ] Полная синхронизация наведения «строка локации ↔ часть плиты».

### P2. Остаток

- [ ] Ссылки на страницы правил и «как рассчитано» для ключевых чисел.
  Нужен подтверждённый источник/URL страниц; не придумывать ссылки.
- [x] Undo/redo и журнал изменений.
- [x] Переключатель анимации кубиков.

### P3. «Становление»

- [ ] Редактирование снаряжения и профиля внутри режима.
- [ ] Остальные текущие значения и полный набор ограничений игрового режима.
- [ ] Не смешивать черновик с обычными правками; проверять «Применить» и
  «Отмена» на каждом пути.

### P4. «Опыт»

- [ ] ER, Experience Rolls, тренировка, изучение, режимы характеристик, магия.
- [ ] Реализовать как второй режим рядом со «Становлением», после P2/P3.

### P5. Мобильный стол и печать

- [ ] Нижняя мобильная панель «Навыки / Здоровье / Снаряжение / Эффекты».
- [ ] Светлая печатная версия A вместо старого `character-preview`.
- [ ] Единая RU/EN-терминология; английские термины — в скобках/тултипах.

### P6. Полировка

- [ ] Портрет, онбординг, подсказки к расчётам, улучшения библиотеки.

## 3. Порядок ближайших итераций

1. **P1:** степени ран, восстановление всех ОЗ, заметка к травме.
2. **P1:** управление эффектами (вкл/выкл, конфликты, эффекты частей тела).
3. **P0:** режим «За столом / Редактирование» и статус сохранения.
4. **P3:** профиль и снаряжение внутри «Становления».
5. **P4:** «Опыт».
6. **P5/P6:** печать, мобильная панель, терминология и полировка.

## 4. Проверки перед коммитом

```bash
npx tsc -p tsconfig.json --noEmit
CHROME_BIN="C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" npm run test:compat
npm run build
```

- На Windows остановить статический сервер перед пересборкой `dist`, иначе
  возможен `EPERM`.
- Для визуальной проверки использовать один локальный порт и переиспользовать
  его после пересборки; PWA-кэш может отдавать старые CSS/JS.
- Проверять 2560, 1920, 1440, 1280, 720 и 390 px; все пять вкладок; окна
  эффекта, проверки, движения, усталости и пикеров.
- Не записывать историю, undo/redo и журнал в JSON персонажа.
