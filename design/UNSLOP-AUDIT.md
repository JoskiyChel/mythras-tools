## Последовательность

Применены проходы unslop: интервалы → палитра → иконки → тексты → типографика → компоновка → состояния → визуальные детали → движение. Компоновка конструктора и листа, порядок разделов, модель Character, JSON и игровые расчёты сохраняются.

Системные шрифты и существующие локальные ресурсы оставлены доступными без сети. Платные генерации изображений не использовались: основа оформления — прикладные элементы самого приложения.

## Проверки

Проверена production-сборка `npm run build` в Chromium 156:

- `npm run test:compat`: **60 тестов успешно**, включая регрессии постоянных травм и стабильности DOM при обновлении Angular.
- Семь основных маршрутов: главная, конструктор, Companion, индекс правил, боевые стили, бой, конвертер статблока. Каждый проверен при ширине **1920, 960 и 390 px**; горизонтального переполнения документа нет.
- Все **19 разделов конструктора** открываются без ошибок.
- Все **10 фаз ведущего** и **5 фаз игрока** открываются без ошибок.
- Проверены **6 справочных диалогов**: усталость, результаты бросков, локации попаданий, наступательные и защитные эффекты, ситуационные модификаторы.
- Companion: удержание клавиатурного фокуса, закрытие Escape и возврат фокуса к вызвавшему навыку; редактор постоянной травмы остаётся доступен после лечения.
- Оба предоставленных JSON: импорт, исходные значения, HP, эффекты и смена цели модификатора, магические навыки, независимая высота карточек, перезагрузка, конструктор, экспорт и повторный импорт, offline-открытие. Исходные пользовательские JSON не записывались в репозиторий.
- Печатное представление действительно сформировало PDF (355568 байт); фиксированные стили `character-pdf` не изменены.
- В итоговых браузерных сценариях **нет ошибок JavaScript**.
- `git diff --check`: успешно. Каталог `docs/` не изменён.

Ограничения: это проверка основных сценариев и выбранных справочных окон, а не ручная проверка каждой строки всех справочников или полная WCAG-сертификация. Часть исходных текстов и названий правил остаётся на английском. Сверка формул движения и прыжков с книгой — прежняя отдельная задача, в этом проходе расчёты не переписывались. При сборке сохраняются три существующих предупреждения NG8102 о `??` в отображении необязательных параметров старого оружия; ошибок сборки нет.

В финальном проходе обнаружено и исправлено ещё одно поведение: getters групп навыков и магии создавали новые контейнеры при каждом change detection. Это удаляло вызывающую кнопку из DOM и мешало восстановлению фокуса. Стабильные `trackBy` сохраняют группы, карточки и записи заклинаний; их DOM-идентичность проверяется отдельным тестом.
