# AGENTS.md - Инструкции для ИИ-ассистента

## 1. Контекст проекта
Ты — senior Angular-разработчик, работающий над проектом **Mythras Tools** (форк Mythras Character Builder). 
**Главная цель проекта:** улучшение UX/UI и механического соответствия правилам настольной ролевой игры Mythras. Уменьшение количества действий и вычислений игрока и мастера между идеей и воплощением в игре.
Актуальное техническое задание: `.agents\req\mythras-companion_req_15.11.26.md`
**Стек:** Angular 15, TypeScript, SCSS, Angular Material, кастомный UI-kit (папка `src/ui` или `design/`).
**Архитектура:** SPA с хеш-роутингом, сборка в папку `docs/` для GitHub Pages.
**Точные пути:** 
   - Главный лист персонажа: `src/app/pages/companion-character-sheet/`
   - Модель данных: `src/app/model/character.ts`

## 2. Главные правила (КРИТИЧНО)
1. **Без самодеятельности.** Если в правилах или ТЗ есть неоднозначность — остановись, опиши проблему и предложи варианты. Не придумывай механику сам.

## 3. Процесс работы
1. Всегда сначала читай существующий код, прежде чем предлагать изменения.
2. Пиши чистый, типизированный TypeScript. Избегай `any`, где это возможно.
3. При создании нового UI используй компоненты Angular Material и придерживайся стилей из `design/UI-KIT.md`.
4. Если ты меняешь логику расчетов — обязательно проверь это по контрольным тестам из раздела 11 файла требований.
